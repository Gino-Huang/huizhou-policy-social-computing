# 研究局限

诚实声明本项目的边界，阅读结论时请一并阅读：

## 1. 热搜 ≠ 民意
热搜榜单是平台算法、运营干预、商业推广与用户行为共同作用的结果，
存在明显的**选择偏差**。本项目测量的是"被平台放大的公共注意力"，
不能直接等同于惠州市民的真实民意或诉求强度。

## 2. 语义相似 ≠ 因果
政策段落与热点标题的向量相似度高，只说明两者在语义空间中接近，
**不能**推出"政策导致了热点"或"热点回应了政策"。任何因果表述
都需要额外的识别策略（如断点、外生冲击），本项目不做因果断言。

## 3. 阈值依赖
语义网络的边、社区、密度都依赖 `similarity_threshold`（默认 0.55）。
阈值是主观选择：调高则网络稀疏、只剩强关联；调低则噪音边增多。
结论必须附带阈值灵敏度分析（见 `evaluation/metrics.py::threshold_sweep`）。

## 4. 地域归因边界
全国性热搜（如台风、通用社会事件）可能与惠州政策文本语义相近，
但事件本身并非惠州本地事务。跨地域热点的归因需要人工核验，
自动化匹配会产生假阳性。

## 5. 模型与语言边界
- 句向量模型对中文网络流行语、缩写、谐音梗的理解有限；
- TF-IDF 基线只捕捉词汇重叠，对转述（paraphrase）不敏感；
- 样本为演示数据时（`data/samples/`），所有数字结论仅作流程演示。

## 6. 时间对齐
政策是"存量文本"（长期有效），热点是"流量快照"（小时级）。
两者时间粒度不同，"政策-热点"匹配本质上是主题对齐而非事件对齐，
解读时间演化图时需注意这一点。
