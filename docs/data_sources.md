# 数据来源说明

## 政策文本（公开、可复现）

| 来源 | 获取方式 | 许可说明 |
|---|---|---|
| 惠州市人民政府官网政策文件 | 政府网站公开下载（.pdf/.txt） | 政府公开信息，合理使用；引用请注明出处 |
| 广东省 / 国家部委相关规划 | 公开渠道下载 | 同上 |

> 仓库中**不存放**政策原文（版权与体积考虑）。复现时请自行从上述公开渠道
> 下载放入 `data/raw/`，再运行 `src/ingestion/policy_loader.py`。

## 社会热点（公开榜单快照）

| 平台 | 数据形态 | 备注 |
|---|---|---|
| 微博热搜 | 定时抓取榜单快照 | 需遵守平台 robots / 使用条款，仅保存标题、排名、热度 |
| 抖音热点 | 定时抓取榜单快照 | 同上 |
| 小红书 | 热榜快照 | 同上 |
| 百度热搜 | 热榜快照 | 同上 |

采集规范：
- 只保存榜单公开字段（标题、排名、热度、时间），不抓取用户个人信息与评论内容；
- 抓取频率遵守平台限流要求；
- 原始快照存 `data/raw/`（gitignored），入库前经 `hotspot_collector.py` 校验去重。

## 合成演示数据

`data/samples/` 下的两个 CSV 为人工编写的虚构数据，仅用于演示流程，
**不得用于任何研究结论**。详见 `data/samples/README.md`。
