# 政策主题识别与协同关系分析（2026-10-14）

> 原计划选题3主线：基于 NLP 与复杂语义网络的惠州市"十五五"发展规划
> 政策主题识别及协同关系研究。
> 输入：863 个政策段落（7 份官方文件：十五五规划纲要、2026 年政府工作报告、
> 法治政府建设年度报告、行政职权调整决定、2026 立法工作计划、
> 2026 重大行政决策事项目录、2026Q1 经济运行简况）；
> 15 个 TF-IDF+KMeans 主题（见 `reports/real_data_run2_20261014.md`）。
> 运行脚本：`scripts/run_policy_synergy.py`；
> 边/指标：`data/processed/synergy_*`；图：`reports/figures/fig4_*`、`fig5_*`。

## 2. 主题之间存在怎样的联系？

以 15 个主题为节点、主题中心向量（TF-IDF 空间）余弦相似度为边权，
保留权重最高的 30 条边，构建主题关联网络。

**关联最强的主题对**（余弦相似度）：

| 主题对 | 相似度 |
|---|---|
| 海洋旅游 — 城乡建设 | 0.497 |
| 投资改革 — 市场立法 | 0.486 |
| 海洋旅游 — 工程规划 | 0.484 |
| 城乡建设 — 养老医疗 | 0.470 |
| 工程规划 — 城乡建设 | 0.456 |
| 科技创新 — 海洋旅游 | 0.439 |
| 企业人才 — 科技创新 | 0.424 |
| 科技创新 — 新材料智能 | 0.423 |

**社群发现**（贪心模块度）得到 5 个社群：

1. **民生治理群**（7 主题）：养老医疗、城乡建设、安全涉外、市场立法、
   投资改革、教育就业、绿色消费——覆盖公共服务、社会治理与市场环境的
   大民生板块。
2. **产业创新群**（4 主题）：企业人才、新材料智能、海洋旅游、科技创新——
   产业发展与科技创新的联动板块；注意海洋旅游同时强连城乡建设与工程规划，
   是跨板块的桥梁主题。
3. **工程—法治对**（2 主题）：工程规划、法治思想。
4. **经济增长**、**行政执法**各自独立成群——前者是经济数据表述的专用语言，
   后者是行政程序文本的专用语言，与其他主题的词汇分布差异较大。

**方法选择说明**：边权采用中心向量余弦相似度而非关键词重叠度（Jaccard），
理由是中心向量是在聚类所用的同一 TF-IDF 特征空间中的分布表示，反映主题
整体语义分布的接近程度；而 top-K 关键词交集对 K 的选择敏感，且"发展/
建设/推进"这类通用词会放大虚假关联。

## 3. 哪些领域可能是跨部门协同的关键节点？

主题关联网络的中介中心性（betweenness）top 5：

| 主题 | 中介中心性 |
|---|---|
| 城乡建设 | 0.275 |
| 海洋旅游 | 0.132 |
| 工程规划 | 0.121 |
| 市场立法 | 0.066 |
| 企业人才 | 0.033 |

解读（严格限定为网络结构描述，不引申为政策建议）：
**城乡建设**的中介中心性显著高于其他主题（约 2 倍于第二名），在网络中
处于连接民生治理群与产业创新群的位置——文本层面上，它是最多主题对之间
最短路径的必经节点。**海洋旅游**同时连接城乡建设、工程规划与科技创新，
是产业板块与建设板块之间的桥梁。**工程规划**连接建设、法治与旅游三个
方向。

关键词共现网络（239 节点 / 307 边，同段共现 ≥2 次）印证了这一结构：
中介中心性最高的关键词是**产业**（0.206）、**人工智能**（0.170）、
**政府**（0.136）、**材料**（0.129）、**文化**（0.126）——"产业"与
"人工智能"是连接最多不同语义社群的词汇枢纽。

## 4. 诚实局限（必读）

1. **共现/相似度 ≠ 因果关系，更不等于政策效果**。本报告所有"关联"都只是
   文本层面的词汇分布相似性：两个主题用词接近，不代表政策上存在协同机制，
   更不能推出"应加强某方面投入"的政策建议。
2. **语料只有 7 份文件**，且以规划纲要和政府工作报告为主；专项规划缺失
   会使某些领域（如科技、人才）的主题颗粒偏粗。
3. **主题建模本身较弱**：TF-IDF+KMeans 的轮廓系数仅 0.013，主题边界是
   近似的；主题关联网络的边权依赖于这些近似主题。
4. **边保留规则是主观选择**：主题图保留 top 30 条边、关键词图要求共现
   ≥2 次——不同的阈值会改变社群划分，结论对参数敏感。
5. 通用词（发展、建设、推进、加强）同时出现在多个主题中，会系统性抬高
   主题间相似度；"最强关联"部分反映的是公文语言的共享，而非实质协同。
