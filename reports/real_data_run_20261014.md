## 2. 关键发现

### RQ1：政策主题结构（初步）
15 个主题中，**主题 11（增长/实施/加强/工程/消费/亿元）独占 1,659 段（41%）**——这是政府工作报告式表述的"通用语言簇"（"增长 x%"、"xx 亿元"、"以上"），而非实质政策主题。其余较可辨识的主题包括：主题 14（产业/集群/石化/材料，195 段）、主题 3（发展/高质量/经济/海洋，275 段）、主题 10（项目/建设/投资，121 段）、主题 7（完善/体系/治理，198 段）、主题 2（企业/服务/养老，195 段）。

**必须诚实说明**：轮廓系数仅 0.014，说明 TF-IDF 在短文本上的聚类结构非常弱。主题 11 这个"大杂烩"簇的存在意味着：**当前主题图是粗糙的第一版**，不宜直接用于严谨的政策解读。改进方向见第 4 节。

### 语义匹配：22/60 热点找到政策关联
- 匹配率 36.7%（22/60），38 个热点无可靠匹配——大多是娱乐、社会新闻类话题（如"肖战又破纪录了""王者荣耀"），本来就没有政策对应，这是符合预期的。
- 语义模型平均最佳相似度 0.519，TF-IDF 基线仅 0.238；两者 Top-1 一致率只有 3.3%，说明句向量确实找到了关键词重叠之外的关联。

**质量最好的匹配示例**（人工核验为真阳性）：
1. 热点「女子6毫米结节确诊乳腺癌」(0.696) → 政策「乳腺癌综合防治体系和救助政策。」——医疗政策 ↔ 医疗热点，教科书级匹配。
2. 热点「铭记"来时路" 走好"康庄道"」(0.718) → 政策「讲好葛洪悬壶济世、东坡寓惠……」——文化宣传话语的对应。
3. 热点「台退役中将戴脚镣高喊：中国必将统一」(0.660) → 政策「围绕全面建成社会主义现代化强国……」——政治话语对应。

**但也发现了假阳性问题**（见第 3 节）：「曝腾讯招商会因撞档肖战演唱会改期」以 0.955 匹配到文件标题残片「惠州市人民政府关于印发《惠州市国民经济和」，「这怎么会是一万」匹配到「消费量10000」（数字巧合）。**高分 ≠ 正确**，短文本的余弦相似度会产生噪音。

### 语义网络
- 二部图（全部 ≥0.55 的边）：3,843 节点、400 条边、密度 0.0018；社区发现得到 3,632 个社区，最大社区 73 节点——网络高度稀疏，大量政策段落是孤立点（符合"一日热点 vs 全量政策"的预期）。
- 按主题聚合边权重：主题 11（通用语言簇）权重最高（117.9），其次是主题 9（公文格式簇，47.8）、主题 12（建设/推进，36.2）。**注意**：这是被"大杂烩"簇主导的结果，主题层面的排名在主题质量提升前仅供参考。
- Top-K 精选边（83 条，已存 parquet）是更干净的分析用边集；400 边全图用于结构观察。两者口径不同，使用时不要混淆。

### RQ3：关注差异
JSD = 0.244（0=分布相同，1=完全不同），属于**中等差异**。热点侧相对更集中在主题 11（+0.179）、主题 9（+0.117）、主题 3（+0.068）；多个政策主题（改革、行政执法、产业集群、企业服务等）在当日热点中零匹配。但**只基于 1 天 60 条热点**，这个数字目前只是基线快照，不能解读为"政府忽视了某领域"或"公众不关心某政策"。

## 3. 诚实的问题清单

1. **段落太短是最大噪音源**。PDF 按句切分后中位数仅 20 字，大量截断残片（如"委托惠东县文""化广电旅游体"）进入匹配池，短文本余弦相似度不可靠，是假阳性的主因。
2. **主题结构弱**（轮廓系数 0.014；41% 落入通用语言簇）。短文本 + TF-IDF 的组合不足以支撑高质量主题图。
3. **阈值 0.55 未经验证**。当前是经验值；需要人工标注 ~100 对候选匹配后，用 Precision@K 和阈值扫描来定（`src/evaluation/metrics.py` 已就绪）。
4. **只有 1 天热点数据**。时间演化、爆发检测、网络动态对比都要等每日快照积累（cron 已运行）。
5. **余弦相似度 ≠ 因果**。边只表示"语义相近"，不表示热点由政策引起。

## 4. 下一步调优（按优先级）

1. **重切分政策文本**：按章节/自然段合并为 100~200 字的段落，匹配阶段只用长度 ≥30 字的段落——预计能消除大部分假阳性。
2. **人工标注 100~200 对**候选匹配，跑 `evaluation/metrics.py` 得到 Precision@K，确定阈值。
3. **主题建模升级**：用句向量 + HDBSCAN/BERTopic 替代 TF-IDF+KMeans，或先做领域规则分类再聚类。
4. 等 7~14 天快照积累后：时间序列、爆发检测、网络演化对比（RQ2/RQ3 的动态部分）。
5. 把清洗后的流程固化为 `scripts/` 可复现脚本，更新 README 的"当前进展"章节。
