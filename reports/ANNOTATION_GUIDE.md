# 人工标注指南：政策–热点语义匹配校准

## 1. 这是什么任务？

我们的算法给每条热搜和每段政策文本计算了一个"语义相似度"分数（0~1）。
分数高代表算法认为两者在说同一件事。但我们发现：**高分不一定真的相关**
（比如某条娱乐八卦曾拿到 0.84 的高分，实际毫无关系），而 0.55 的阈值
是从没验证过的经验值。

你的任务：给 `data/processed/annotation_batch_20261014.csv` 里的约 120 对
"热搜–政策段落"打标签（0/1/2）。我们用你的标注计算每个分数段的真实
准确率，从而**用数据决定阈值**，而不是拍脑袋。

## 2. 标签定义

只看**语义上是否在讨论同一件事**，不要只看有没有相同关键词。

### 2 = 直接相关（同一具体议题）

热搜和政策段落在说同一件具体的事。

- 例 A：热搜「女子6毫米结节确诊乳腺癌」→ 政策「乳腺癌综合防治体系和救助政策。」
  （同一议题：乳腺癌防治）
- 例 B：热搜「网传"禁止教师用AI备课"系误读」→ 政策「…推进人工智能助力教育变革，
  加强人工智能通识教育…」（同一议题：AI 与教育教学）

### 1 = 部分相关（同一大领域，不同具体议题）

两者属于同一政策领域，但具体说的不是一件事。拿不准时选 1，不要选 0。

- 例 A：热搜「医生回应乳腺微小结节为何容易漏诊」→ 政策「推行"分布式检查、
  集中式诊断"…培育建设20个以上省级临床特色专科…」
  （都是医疗领域，但一个讲结节漏诊、一个讲检查检验改革）
- 例 B：热搜「网传"禁止教师用AI备课"系误读」→ 政策「…教师高质量发展行动…
  建立适应生源变化的师资配置机制…」
  （都是教育/教师领域，但一个讲 AI 备课、一个讲师资配置）

### 0 = 不相关（无实质语义关联）

两者在说完全不同的事，即使有相同词汇或分数很高。**这是最重要的标签**，
专门用来抓算法的"高分假阳性"。

- 例 A：热搜「曝腾讯招商会因撞档肖战演唱会改期」→ 政策「…惠州市人才发展
  促进条例草案…」（娱乐八卦 vs 立法计划，毫无关系——尽管算法给了 0.74）
- 例 B：热搜「这怎么会是一万」→ 政策「…规上工业总产值13349亿元…」
  （随口感叹 vs 工业统计，毫无关系）

## 3. 怎么填表

1. 用 Excel / WPS / Google Sheets 打开
   `data/processed/annotation_batch_20261014.csv`
   （文件是 UTF-8 with BOM 编码，中文不会乱码）。
2. 只填两列：
   - `relevance`：填 `0`、`1` 或 `2`（必填，每行都要填）；
   - `annotator_notes`：可选，写下你犹豫的原因（比如"疑似相关但不确定"）。
3. **不要改其他列**（pair_id、标题、政策文本、相似度分数等）。
4. 保存时保持 CSV 格式（不要存成 xlsx）。
5. 填完后把文件放回原路径（覆盖原文件即可），然后告诉我。

## 4. 预计时间

约 120 对，每对看 10~20 秒，**总计约 30~45 分钟**。建议一次完成，
避免前后标准漂移。如果中途累了，保存进度下次继续即可（空着 relevance 的行
会被脚本忽略并提示）。

## 5. 标注之后会发生什么

我运行 `scripts/score_annotations.py`，它会：

1. 计算每个分数段（如 0.70~1.00、0.60~0.70…）的真实准确率——
   直接回答"0.6 分以上的匹配有百分之多少是真的相关"；
2. 对阈值 0.30~0.80（步长 0.05）做扫描，输出每个阈值的
   precision / recall / F1（分"严格口径：只算 2 为正例"和
   "宽松口径：1 和 2 都算正例"两种）；
3. 推荐 F1 最高的阈值，并保存 `reports/threshold_calibration.md`。

之后我们就用校准后的阈值重跑匹配，并考虑换中文领域 embedding 模型做对照。

## 6. 注意事项

- 按**你的第一直觉**判断，不要过度思考；一致性比完美更重要。
- 警惕"关键词陷阱"：两句话都有"发展""建设""推进"不代表相关，
  这些是公文高频词。
- 警惕"数字陷阱"：都有数字（如"一万" vs "10000"）不代表相关。
- 如果某对让你非常犹豫，标 1 并在 annotator_notes 里写一句原因。
- 你的标注只用于校准我们自己的模型阈值，不对外发布。
