# 方法说明

## 研究问题
- **RQ1**：惠州"十五五"政策文本的主题结构是什么？（主题建模）
- **RQ2**：政策主题与社会热点之间存在怎样的语义关联？（语义匹配 + 二部网络）
- **RQ3**：政策议程与公众注意力在主题分布与时间演化上有何差异？（JSD 散度 + 爆发检测）

## 算法链（四层）

```
政策原文 (.txt/.md/.pdf)                热点榜单快照 (CSV)
        │                                        │
        ▼                                        ▼
┌─ 1. 预处理 ──────────────────┐   ┌─ 采集校验 ─────────────┐
│ 清洗→分句→jieba分词→去重      │   │ schema校验→时间解析→去重 │
└──────────────┬───────────────┘   └────────────┬───────────┘
               │                                │
               ▼                                ▼
┌─ 2. 主题建模 ─┐                    ┌─ 3. 语义匹配 ──────────────┐
│ TF-IDF 基线    │                    │ 句向量余弦 / TF-IDF基线     │
│ KMeans+轮廓系数 │                    │ Top-K + 阈值(0.55)→匹配表   │
└───────┬───────┘                    └─────────────┬──────────────┘
        │                                          │
        └──────────────┬───────────────────────────┘
                       ▼
            ┌─ 4a. 语义网络 ──────────────┐
            │ 政策-热点二部图（边权=相似度）│
            │ 加权度排名 / 投影 / 社区发现  │
            └──────────────┬──────────────┘
                           ▼
            ┌─ 4b. 差异与演化 ────────────┐
            │ 主题分布 JSD 散度            │
            │ 日频计数→滑动平均→z-score爆发 │
            │ 分平台热度（禁止跨平台求和）  │
            └────────────────────────────┘
```

## 关键设计决策

1. **双基线对照**：TF-IDF 余弦作为可解释基线，句向量作为语义泛化方法；
   两者 Top-K 重合度本身就是一个汇报指标。
2. **阈值 + None 机制**：无达标匹配记为 None 而非硬匹配，避免虚假关联
   进入网络；阈值灵敏度扫描量化结论稳健性。
3. **平台热度隔离**：各平台热度口径不同，只做平台内标准化与排名百分位，
   跨平台比较只用无量纲指标。
4. **评估闭环**：人工标注（0/1/2 三级）→ P@K/R@K → 阈值扫描 → 回到阈值选择。

## 复现步骤
1. `pip install -r requirements.txt`
2. 政策原文放入 `data/raw/`，运行 `python -m src.ingestion.policy_loader`（或见 notebooks）
3. 热点快照 CSV 整理后运行 `src/ingestion/hotspot_collector.py`
4. 按 `src/` 模块顺序执行 pipeline（示例见 `notebooks/`）
5. `streamlit run app.py` 打开交互仪表盘
