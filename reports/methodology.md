# 方法说明（完整版，2026-10-14）

> 本项目遵循原计划选题3：基于 NLP 与复杂语义网络的惠州市"十五五"
> 发展规划政策主题识别及协同关系研究。社会热点对照为扩展模块。

## 0. 研究问题（原计划）

- **RQ1**：惠州"十五五"规划重点关注哪些发展主题？（政策主题识别）
- **RQ2**：产业、人才、交通、创新与生态等政策主题之间存在怎样的联系？
  哪些领域可能成为跨部门协同的关键节点？（协同关系网络）
- **RQ3（扩展）**：政策议程与公众注意力（社会热点）在语义关联与主题
  分布上有何差异？随时间如何演化？

## 1. 数据

| 数据 | 规模 | 来源 |
|---|---|---|
| 政策文件 | 7 份官方文件 | 惠州市政府官网政府公报附件、部门页面（见 `data/raw/SOURCES.md`）：十五五规划纲要（99 页 PDF）、2026 年政府工作报告（官网 HTML 提取）、法治政府建设年度报告、行政职权调整决定、2026 立法工作计划、2026 重大行政决策事项目录、2026Q1 经济运行简况 |
| 政策分析单元 | 863 个段落（均值 116 字） | 4,621 个 PDF/HTML 抽取短句 → 去重 → `src/preprocessing/segment_merger.py` 按句边界合并为 100~200 字段落（provenance 完整保留，零丢失） |
| 社会热点快照 | 每日 2 平台 × top 30 | 微博热搜、百度实时热搜，每日定时采集（见 `data/raw/hotspots/COLLECTION_LOG.md`） |

## 2. 算法链

```
政策原文 (.pdf/.txt)                         热点榜单快照 (CSV)
        │                                            │
        ▼                                            ▼
┌─ 1. 预处理 ───────────────────┐     ┌─ 采集校验 ───────────────┐
│ 清洗→分句→jieba分词→去重        │     │ schema校验→时间解析→去重   │
│ →段落合并(100~200字,≥30字)      │     └────────────┬─────────────┘
└───────────────┬───────────────┘                    │
                │                                    │
                ▼                                    ▼
┌─ 2. 主题建模 ─────────────────┐     ┌─ 3. 语义匹配(扩展模块) ──────┐
│ TF-IDF + KMeans(k=8~15,        │     │ 句向量余弦相似度              │
│ 以轮廓系数+可解读性选k=15)       │     │ Top-K + 阈值→匹配表            │
└───────┬───────────────────────┘     │ (阈值经人工标注校准,见§4)       │
        │                             └──────────────┬──────────────┘
        ▼                                            │
┌─ 4. 协同网络分析(主线) ──────────────────────────────┐│
│ a) 关键词共现网络：段内共现≥2次为边(239节点/307边)    ││
│ b) 主题关联网络：主题中心向量(TF-IDF空间)余弦相似度   ││
│    为边权，保留top-30边                              ││
│ c) 社群发现(贪心模块度) + 中介中心性→协同关键节点      ││
└──────────────────────┬──────────────────────────────┘│
                       │                               │
                       ▼                               ▼
            ┌─ 5. 交互展示 ──────────┐   ┌─ 6. 差异与演化(扩展) ───┐
            │ Streamlit 6个页面      │   │ 主题分布JSD散度         │
            │ Plotly交互网络图       │   │ 日频→滑动平均→z-score   │
            └──────────────────────┘   │ 分平台热度(禁跨平台求和)  │
                                       └─────────────────────────┘
```

### 各环节说明

1. **预处理**：PyMuPDF/HTML 抽取 → 去版式噪音 → jieba 分词 → 精确+近似去重。
   短句级段落（中位 ~20 字）会产生余弦假阳性（数字巧合、截断残片），故用
   `segment_merger` 合并为 100~200 字段落，最短 38 字。
2. **主题建模**：TF-IDF（jieba 分词器）+ KMeans。k=15 为可解读性与规模均衡
   的选择；轮廓系数仅 0.013（见 §5 局限）。主题标签人工核验关键词后命名。
3. **协同网络**：关键词共现图回答"哪些概念经常一起出现"；主题关联图
   （中心向量余弦）回答"哪些政策领域在文本分布上接近"；中介中心性识别
   在最多主题对最短路径上的枢纽主题，即网络结构意义上的协同关键节点。
4. **语义匹配（扩展）**：句向量（默认 `paraphrase-multilingual-MiniLM-L12-v2`，
   见 §4 标注实验结论）编码政策段落与热点标题，余弦相似度 Top-K 检索；
   低于阈值记为"无可靠匹配"而非硬匹配。TF-IDF 余弦始终作为可解释基线对照。

## 3. 核心发现（截至 2026-10-14）

- **重点主题**：城乡建设（141 段/16.3%）、海洋旅游（94）、养老医疗（76）；
  产业侧（企业人才/科技创新/新材料智能）合计约 20%。
- **最强主题关联**：海洋旅游—城乡建设（0.497）、投资改革—市场立法（0.486）、
  海洋旅游—工程规划（0.484）；5 个社群（民生治理×7、产业创新×4、
  工程规划+法治思想、经济增长/行政执法独立）。
- **协同关键节点**（中介中心性）：城乡建设（0.275）、海洋旅游（0.132）、
  工程规划（0.121）；关键词枢纽：产业（0.206）、人工智能（0.170）。
  详见 `reports/policy_synergy_20261014.md`。

## 4. 人工标注实验（阈值校准）

- 标注集：120 对（按相似度分层抽样：[0.70,1.00] 3 对、[0.60,0.70) 4 对、
  [0.50,0.60) 23 对、[0.40,0.50) 24 对、[0.30,0.40) 66 对；每热点每段
  ≤3 对），人工三级标注：2=直接相关、1=部分相关、0=不相关。
  指南见 `reports/ANNOTATION_GUIDE.md`，标注文件
  `data/processed/annotation_batch_20261014.csv`。
- **结论**：标注结果 97×0 / 15×1 / 8×2。**所有 ≥0.60 的候选全被标为 0**
  （模型对"正式公文 vs 微博口语"配对系统性高估，如 0.74 的娱乐→立法对）；
  8 个确认的 2 分布在 0.31~0.56。阈值扫描最佳 F1 对应精度仅 ~0.10~0.20——
  **阈值无法修复，问题在模型本身**。该标注集现为项目的金标准评估集。
- 模型对决（`scripts/model_shootout.py`，`reports/model_shootout_20261014.md`）：
  在同一标注集上，`BAAI/bge-small-zh-v1.5` 严格口径 F1=0.308（阈值 0.45），
  约为原模型（0.158）的 2 倍，且 ≥0.60 离群高分完全消失。
  **已据此更换默认模型并将阈值校准为 0.45**（见 `configs/config.yaml`）。

## 5. 诚实局限（必读）

1. **共现/相似度 ≠ 因果关系，更不等于政策效果**。所有"关联"只是文本层面
   的词汇分布相似性，不能推出"应加强某方面投入"等政策建议。
2. **主题建模弱**：TF-IDF+KMeans 轮廓系数 0.013，主题边界是近似的；
   协同网络的边权依赖于这些近似主题。
3. **语料有限**：7 份文件，以纲要和工作报告为主；专项规划缺失使部分
   领域颗粒偏粗。
4. **热点侧单日基线**：时间演化分析需 7~14 天快照积累，目前只有首日数据；
   JSD 等分布指标在快照增多前没有政策含义。
5. **阈值结论依赖 120 对标注**：标注者单一、无多人一致性检验；结论外推
   到全量匹配时需谨慎。
6. **通用词抬高相似度**："发展/建设/推进/加强"同时出现在多主题中，
   系统性抬高主题间相似度；"最强关联"部分反映公文语言共享。

## 6. 复现步骤（从 fresh clone）

```bash
git clone <repo> && cd huizhou-policy-social-computing
pip install -r requirements.txt          # 含 streamlit/plotly/scikit-learn/jieba
pytest tests/ -q                          # 26 项，句向量延迟加载，测试不下载模型
# 真实数据流程：
python scripts/run_real_analysis_v2.py     # 清洗→重切分→主题→匹配→网络→JSD（~5分钟，模型已缓存）
python scripts/run_policy_synergy.py       # 关键词共现 + 主题协同网络
streamlit run app.py                      # 6 页面交互仪表盘
# 标注与校准：
python scripts/score_annotations.py        # 需先填写 annotation_batch 的 relevance 列
python scripts/model_shootout.py          # 模型对决（需下载对照模型）
```

Windows 用户：句向量模型默认下载到 C 盘用户目录；运行前设置
`HF_HOME` / `HUGGINGFACE_HUB_CACHE` 指向 D 盘（见 README）。
