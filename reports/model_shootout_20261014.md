# 句向量模型对决（2026-10-14）

> 背景：120 对人工标注（97×0 / 15×1 / 8×2）证明默认模型
> `paraphrase-multilingual-MiniLM-L12-v2` 在本任务上不可靠——
> 所有相似度 ≥0.60 的候选全被标为 0（正式公文 vs 微博口语的系统性高估）。
> 本实验在同一标注集上对比中文领域挑战者，裁决是否更换默认模型。
> 运行脚本：`scripts/model_shootout.py`；原始数字：
> `data/processed/model_shootout_20261014.json`。

## 参选模型

| 模型 | 说明 |
|---|---|
| 现任：`paraphrase-multilingual-MiniLM-L12-v2` | 多语言通用句向量，384 维 |
| 挑战者：`BAAI/bge-small-zh-v1.5` | 中文领域句向量，512 维，~100MB |

评估方法：用各模型重算 863 政策段落 × 60 热点标题的余弦相似度矩阵，
在 120 对标注上比较——各分数段准确率（严格 rel==2 / 宽松 rel>=1），
以及阈值 0.30~0.80（步长 0.05）扫描的 P/R/F1。

## 结果

### 分数段准确率

| 分数段 | 现任 n | 现任严格/宽松准确率 | 挑战者 n | 挑战者严格/宽松准确率 |
|---|---|---|---|---|
| [0.70, 1.00] | 3 | 0.00 / 0.00 | 0 | —（该段无候选） |
| [0.60, 0.70) | 4 | 0.00 / 0.00 | 0 | —（该段无候选） |
| [0.50, 0.60) | 23 | 0.13 / 0.22 | 3 | 0.33 / 0.67 |
| [0.40, 0.50) | 24 | 0.04 / 0.29 | 35 | 0.17 / 0.37 |
| [0.30, 0.40) | 66 | 0.06 / 0.17 | 54 | 0.02 / 0.15 |

**关键**：挑战者的相似度整体分布更收敛（全矩阵最大值 0.575），
≥0.60 的离群高分区**完全消失**——现任模型的校准伪影在挑战者上不存在。

### 阈值扫描（严格口径，rel==2 为正例）

| 阈值 | 现任 P / R / F1 | 挑战者 P / R / F1 |
|---|---|---|
| 0.35 | 0.048 / 0.500 / 0.088 | 0.129 / 1.000 / 0.229 |
| 0.40 | 0.074 / 0.500 / 0.129 | 0.184 / 0.875 / 0.304 |
| 0.45 | 0.081 / 0.375 / 0.133 | **0.222 / 0.500 / 0.308** |
| 0.50 | 0.100 / 0.375 / 0.158 | 0.333 / 0.125 / 0.182 |
| 0.55 | 0.067 / 0.125 / 0.087 | 0.000 / 0.000 / 0.000 |

- 现任最佳：F1=0.158 @0.50（P=0.10，R=0.375）
- 挑战者最佳：**F1=0.308 @0.45（P=0.222，R=0.500）**——严格口径 F1 约为现任的 **2 倍**
- 宽松口径（rel>=1）：现任最佳 F1=0.322 @0.30；挑战者最佳 **F1=0.492 @0.40**
  （P=0.395，R=0.652）

## 裁决：更换默认模型

`BAAI/bge-small-zh-v1.5` 在两个口径下全面优于现任模型，且消除了
≥0.60 离群高分伪影。决定：

1. `configs/config.yaml` 的 `model.name` 切换为 `BAAI/bge-small-zh-v1.5`；
2. `matching.similarity_threshold` 由 0.55 调整为 **0.45**
   （标注集上严格口径 F1 最高点）。

诚实说明：即使是胜者，严格口径精度也只有 0.22——语义匹配仍是本项目
最弱的一环，阈值结论依赖单标注者的 120 对样本。后续可用 cross-encoder
重排或更多标注继续改进；本对决只证明"换模型显著更好"，不证明"已够好"。
